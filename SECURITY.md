# Security policy

Please report vulnerabilities privately — **do not open a public issue**.

- Preferred: GitHub → **Security → Report a vulnerability** (private vulnerability reporting).
- Alternatively: follow the instructions at <https://faridmahmudlu.dev/security/>
  (machine-readable: <https://faridmahmudlu.dev/.well-known/security.txt>).

Scope, safe-harbour terms and response times are described on the security page.
